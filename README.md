This is my attempt to make a minimal blog using Sveltekit.

I built it by trying to make https://cloudcannon.com/tutorials/sveltekit-beginner-tutorial work with the latest version of Svelte, informed by the [Svelte and Sveltekit tutorials](https://svelte.dev/tutorial/svelte/welcome-to-svelte), with some assistance getting individual blog posts working from https://github.com/josh-collinsworth/sveltekit-blog-starter.

To view locally, cd into the `my-app` directory and run `npm install` and then `npm run dev`.
